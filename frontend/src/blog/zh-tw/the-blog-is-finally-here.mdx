C++ Here 一直以來只有兩個頁面：首頁和編輯器。有些東西放不進這兩個地方，例如新功能的介紹、競程的小技巧、編譯器背後的故事，所以我們加了這個 Blog。這第一篇正經的文章，就來聊聊它本身。

## 為什麼要有 Blog

編輯器的目標是讓你打開就能寫程式，所以介面上能放的說明很有限。很多功能做好了，卻沒有地方好好介紹：

- 為什麼程式可以直接在瀏覽器裡編譯，不用送到伺服器
- 測試案例要怎麼用，才能在比賽時省下最多時間
- 一些我們在開發過程中踩過、覺得值得分享的坑

這些內容之後都會寫在這裡。

## 它是怎麼做出來的

整個網站本來就是用 [Astro](https://astro.build) 寫的，所以 Blog 也直接沿用。每篇文章就是一個 Markdown 檔，網站在建置時把它轉成網頁，不需要資料庫，也不需要後台。寫文章就跟寫筆記一樣，寫完存檔就是一篇新文章。

文章的排版交給 [shadcn/typeset](https://ui.shadcn.com/docs/typeset)。它是一份專門給文章用的樣式，標題、清單、表格和程式碼都會自動排好，我們只要專心寫內容。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    cout << "Hello, blog!\n";
}
```

> 既然是 C++ 的網站，程式碼區塊當然要好讀。

## 中文和英文

C++ Here 本來就支援多種語言，Blog 也一樣。文章會盡量同時有中文和英文版，兩個版本會互相連結，你可以在網址列直接切換。如果某篇文章還沒有中文版，中文的列表裡會先放英文版，不會讓你點進一個空白頁。

## 怎麼追蹤新文章

最簡單的方式是訂閱 RSS：

- 英文：[`/en/blog/rss.xml`](/en/blog/rss.xml)
- 中文：[`/zh-tw/blog/rss.xml`](/zh-tw/blog/rss.xml)

或者偶爾回來看看，首頁最下方就有 Blog 的連結。
